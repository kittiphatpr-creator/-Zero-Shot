เลือกหมวดหมู่ (Multi-Domain Selection)
1. อัปโหลดรูปภาพ (Upload Image)
คลิกเพื่อเลือกภาพ หรือลากไฟล์มาวางที่นี่
รองรับ JPG, PNG, WebP หรือกด Ctrl+V เพื่อวางรูปภาพ
ภาพตัวอย่างพร้อม Prompt ทันใจ:
Avengers
Batman
Superman
Justice League
แซลมอน
ไข่ดาว
แมว
2. ป้อนสิ่งของที่ต้องการค้นหา (Prompt)
ระดับความมั่นใจ (Confidence Threshold) 25%
โหมดโมเดล: ⚡ Zero-Shot YOLO-World
พบวัตถุ: 0 รายการ
ความเร็ว: ~0 ms
รายการวัตถุที่ตรวจพบ
กดปุ่ม "ค้นหาและตีกรอบวัตถุ" เพื่อดูรายการและพิกัดของวัตถุ
ศูนย์การฝึกฝนและเทรนโมเดล AI (Fine-Tuning Studio)
1
รวบรวมรูปภาพ
ใส่รูปภาพที่ต้องการสอน AI ลงในโฟลเดอร์ เช่น ภาพอาหาร เสื้อผ้า ยานพาหนะ
2
Auto-Labeling
ระบบใช้ Zero-Shot AI ตีกรอบวัตถุให้อัตโนมัติ แปลงเป็น YOLO format โดยไม่ต้องวาดกรอบเอง
3
PyTorch Fine-Tuning
ฝึกฝนโครงข่ายประสาทเทียมด้วย Ultralytics บันทึกค่าน้ำหนักเป็น best.pt พร้อมใช้งาน
สถานะ: พร้อมเริ่มต้น 0%
[พร้อมทำงาน] รอคำสั่งเพื่อเริ่มต้นกระบวนการ Auto-Labeling และ Fine-Tuning...
หรือรันคำสั่งโดยตรงผ่าน Terminal / PowerShell:
python train_custom_dataset.py --images static/samples --classes "ไข่ดาว, ข้าว, รถยนต์" --epochs 5
